# it-english-academy
**IT English Academy** — учебное веб-приложение для изучения технического английского языка. Оно предназначено для студентов IT-направлений и начинающих специалистов, которым нужно запоминать английские термины, встречающиеся в программировании, веб-разработке, базах данных и компьютерных сетях.

## Возможности

- просмотр словаря IT-терминов;
- поиск по английскому слову и русскому переводу;
- фильтрация терминов по категориям;
- интерактивные карточки с переводом и примером предложения;
- отметка выученных слов;
- тест с подсчётом результата;
- сохранение прогресса в `localStorage`.

## Использованные технологии

- HTML5 — структура приложения;
- CSS3 — оформление и адаптация под мобильные устройства;
- JavaScript — логика приложения;
- DOM API — создание элементов через `createElement`, добавление через `appendChild`, обработчики `addEventListener`, изменение классов через `classList`;
- ES Modules — разделение JavaScript на модули с помощью `import` и `export`;
- localStorage — сохранение прогресса в браузере.


## Как запустить локально

1. Скачать или клонировать проект.
2. Открыть папку проекта в редакторе кода, например VS Code.
3. Запустить `index.html` через локальный сервер. В VS Code можно использовать расширение Live Server.
4. Открыть адрес, который покажет Live Server.
